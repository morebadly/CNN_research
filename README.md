# Quant-for-babies 第 1—8 章代码与学习说明

本仓库收录八个 UTF-8 Python 练习文件，由原项目的八章 Notebook 导出，包含本地练习修改。原有注释随代码保留。Notebook 的讲解、公式和练习转为 Python 注释，按原顺序与代码穿插排列。

来源：[ThreshoLdnnis/Quant-for-babies](https://github.com/ThreshoLdnnis/Quant-for-babies/tree/main/notebooks)。

来源版本：[`711ca83a82f6f1bb1745c6ca28c1ed3ecd2a97bd`](https://github.com/ThreshoLdnnis/Quant-for-babies/commit/711ca83a82f6f1bb1745c6ca28c1ed3ecd2a97bd)。每个 Python 文件开头均附有对应 Notebook 的来源链接和 Git blob SHA。原项目采用 MIT 许可证，见 [LICENSE](LICENSE)。

## 文件与章节对应

仓库第一期 `phase1_intro` 对应第 1—4 章，第二期 `phase2_intro` 对应第 5—8 章。第二期原文件名从 `01` 重新编号，此处统一编号为 `05`—`08`。

| 章 | 本地文件 | 核心问题 | 主要代码与实验 |
| --- | --- | --- | --- |
| 1 | `01_什么是量化金融.py` | 什么是量化，如何把想法变成可检验的规则？ | 模拟股价与均线；对比规则策略、随机买卖和买入持有；模拟随机游走、概率优势与凯利仓位；下载 AAPL 真实行情。 |
| 2 | `02_你的第一个量化实验.py` | 如何读取行情、计算和观察涨跌？ | 认识 OHLCV；用 `pct_change()` 计算日收益率；绘制收益率曲线、直方图和累计收益曲线；比较 AAPL、TSLA、NVDA 的波动。 |
| 3 | `03_移动平均线策略.py` | 如何把趋势判断写成交易信号？ | 区分趋势与噪声；用 `rolling().mean()` 计算 MA5、MA20；识别金叉、死叉；生成持仓信号并标注买卖点。 |
| 4 | `04_策略回测.py` | 双均线规则在历史数据里表现怎样？ | 用 `shift(1)` 将信号滞后一期；计算策略收益和净值；与个股买入持有、大盘基准比较；统计完整交易回合胜率和最大回撤。 |
| 5 | `05_理解波动率.py` | 同样的最终收益，为什么持有体验不同？ | 用收益率标准差度量波动、乘 `sqrt(252)` 年化；比较股票波动率；模拟不同波动的净值路径；绘制风险收益散点图。讲解还涉及波动率研究脉络、样本误差与估计局限。 |
| 6 | `06_夏普比率与Beta.py` | 收益相对于风险是否划算，与大盘有多同步？ | 计算年化收益、年化波动和简化夏普比率；绘制多标的风险收益图；以 SPY 为基准计算 Beta，并用 NumPy、pandas 交叉核对；用 `statistics` 观察收益分布。 |
| 7 | `07_最大回撤与仓位管理.py` | 账户从高点最深跌过多少，仓位如何影响结果？ | 计算历史净值高点、每日回撤和最大回撤；绘制水下曲线；比较双均线满仓、半仓以及买入持有的净值和回撤。 |
| 8 | `08_多标的组合与相关性.py` | 多买几只标的能否降低波动？ | 对齐多标的价格和收益率；计算 Pearson 相关性矩阵并画热力图；构建等权组合；比较组合与单标的波动，并与 SPY 的净值曲线对照。 |

学习顺序是：量化思维 → 行情与收益率 → 交易规则 → 历史回测 → 波动风险 → 风险调整收益与市场敏感度 → 回撤与仓位 → 多标的组合。

## 如何阅读与运行

建议使用 Python 3.10 或更高版本。`requirements.txt` 从同一版本的原仓库原样复制。在此目录的终端安装依赖：

```powershell
python -m pip install -r requirements.txt
```

文件内的 `# %%` 对应原 Notebook 单元，`# %% [markdown]` 对应原讲解单元。可以在安装 Python 和 Jupyter 扩展的 VS Code 中，按单元从上往下运行。

原代码使用 Notebook 提供的 `display()`。也可以在 IPython 中运行文件，例如：

```powershell
ipython .\02_你的第一个量化实验.py
```

第三章需要按原文选择数据源：搜索 `【海外用户】` 或 `【大陆用户】`，分别对应原 Notebook 的第 10、12 单元。先运行环境与前置实验，再选择 yfinance 美股下载或 AkShare A 股下载中的一段，接着运行均线和策略分析。整文件顺序执行会依次尝试两套下载代码，因此第三章建议按单元运行。

行情下载部分需要联网；下载结果与运行日期、数据接口状态有关。中文绘图使用原文指定的字体，出现中文缺字时可按注释调整为本机已有字体。
